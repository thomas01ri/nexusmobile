# NEXUS Mobile v1.0.2 — Android UI Prototype

NEXUS is an independent Android launcher/interface prototype for a GTA San Andreas multiplayer client concept.

## Included
- Home page with quick-connect entry point
- Server browser: add/select/delete saved server entries
- Local nickname profile
- Local settings toggles
- About page that explains missing game/multiplayer core
- NEXUS logo, launcher icon, concept wallpaper
- Android version 1.0.2 (versionCode 102)

## Important limitations
This is a standalone launcher/UI prototype. It does **not** contain GTA San Andreas, SA-MP multiplayer core, or server connection/gameplay implementation. The connect UI is not a working multiplayer connection.

## Build an installable APK using GitHub Actions (cloud build)
This repository includes a workflow at `.github/workflows/build-apk.yml` that builds a debug APK on GitHub's hosted runner.

1. Create a GitHub repository and upload/push the contents of the `NexusMobile` folder to the repository's `main` branch.
2. Open the repository's **Actions** tab.
3. Choose **Build NEXUS APK** from the workflow list.
4. Tap **Run workflow** (or wait for a build after pushing to `main`).
5. Wait until the run finishes successfully, open that run, and download the artifact named **NEXUS-Mobile-v1.0.2-APK**.
6. Extract the artifact ZIP to get `NEXUS-Mobile-v1.0.2-debug.apk`, then install it on Android. If Android prompts, allow installation from that file manager/browser for this APK.

The APK is generated by the workflow; it is not included in this source ZIP. This environment has no Android SDK/Gradle installation, so a local APK build has not been run or verified here.


## Build locally (Android Studio)
Open this folder in Android Studio, let Gradle sync, then use **Build > Build APK(s)**. Output normally appears under `app/build/outputs/apk/debug/`.
